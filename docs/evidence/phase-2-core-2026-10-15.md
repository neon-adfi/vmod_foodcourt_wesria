## Review disposition and intentional limits

- Independent final review found no remaining security or data-integrity blocker. Expired-list filtering, revoke confirmation, last-name error rendering and asset evidence findings are resolved.
- Mail exception logs now use the required `[IdentityService]` / `[InvitationService]` tags, safe exception class and invitation ID where applicable. Intentional privacy exception to the broad plugin logging standard: raw exception messages and trace arguments are omitted because mail transports may embed credentials, message contents or bearer tokens. This reduces transport diagnostics; provider qualification can add a specifically redacted diagnostic path when needed.
- Resend deliberately replaces the prior token. Messages can arrive out of order; older links remain invalid regardless of delivery order. A valid pending invitation can be resent; an expired invitation can be issued again through the same form. No delivery queue or invitation-specific role snapshot was added.
- One company-row lock serializes Core administration. A separate fixed native MySQL advisory lock serializes low-volume Core account creation to respect the existing case/accent-insensitive email collation. Other native account writers must use that account lock or a separately approved native-schema uniqueness change. Public registration is disabled.
- Same-session requests use Laravel's native database lock store because file locks failed on this host bind mount. No ERP operation is implemented or placed under the company administration lock.
- Generic recovery reports the request without confirming whether an account exists or whether mail arrived. Invitation transport failures explicitly retain the pending invitation and report the failed send.
- Mail was accepted only by the native **log** transport. External provider delivery, inbox placement, production operation and human acceptance are not claimed. Three inherited SVG sanitizer advisories remain as disclosed in Phase 1; dependencies were not changed here.
- The matching target code graph was unavailable; implementation, call sites, installed native auth/middleware and tests were traced directly. Native behavior was also checked against [Laravel 12 CSRF](https://laravel.com/framework/docs/12.x/csrf) and [session blocking](https://laravel.com/framework/docs/12.x/session) documentation. Installed sources take precedence over a Context7 response for the wrong major version.
